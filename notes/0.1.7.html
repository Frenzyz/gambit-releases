Gambit 0.1.7

  • Safari-style chrome: horizontal tabs, a tighter toolbar, and secondary actions in the More menu. Downloads open in a shelf beside the page.
  • Ask keeps working through long tasks. The consecutive tool-round cap is removed, and local Ask is routed with the Fastino decision model.
  • Chromium script evaluation no longer crashes the helper. Extension actions use a Chrome-like panel, and Google sign-in stays on WebKit.
  • Private windows stay dark with readable menus. Failed and 404 loads show a host error page, and Command-T opens a new tab.
